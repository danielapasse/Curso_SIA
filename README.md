# Curso SIA - Variaveis ambientais
Repositório contendo o script utilizado para o curso "Extração e uso de variáveis ambientais a partir de bancos de dados públicos", ministrado durante o Simpósio de Integração Acadêmica - SIA, realizado na Universidade Federal de Viçosa - UFV.

O GitHub possui um limite de armazenamento em sua versão gratuita, por isso, os arquivos utilizados para executar esse script foram disponibilizados em uma pasta. O acesso a pasta pode ser feito através do link do google drive abaixo. Ressalto que, como a pasta está compactada no formato .zip, é necessário descompactar a pasta após o download para ter acesso aos arquivos.
